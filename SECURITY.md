# Security policy

This project processes untrusted audio paths and invokes external media tools. Please
report vulnerabilities involving command execution, path handling, resource
exhaustion, input validation, or data exposure privately before public disclosure.

Include the affected commit, operating system, Go and FFmpeg versions, a minimal
reproduction where safe, and expected versus actual behaviour. Do not attach private
recordings or personal data; use a synthetic sample where possible.

The project currently has no guaranteed response-time SLA.
