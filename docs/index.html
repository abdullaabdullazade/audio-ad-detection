How to read these results

  • The radio archive has no ground-truth labels, so the 684 detections are not a precision or recall figure. They are published in full so anyone can listen and judge.
  • Confidence is a global score from DTW alignment quality and spectral-peak agreement; it is comparable across adverts.
  • Latency is the wall time to process one 61-minute recording against all three adverts.
  • The full recordings (about 32 GB) are not published; only the detected excerpts are.
